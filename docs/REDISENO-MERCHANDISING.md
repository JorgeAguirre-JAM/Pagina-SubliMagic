# Rediseño Subli-Magic — Agencia de merchandising

## Posicionamiento

Subli-Magic se presenta como una agencia de merchandising, no únicamente como un negocio de sublimación o DTF.

El sitio contempla soluciones para:

- Personas y emprendimientos.
- Marcas y empresas.
- Equipos y clubes.
- Creadores.
- Eventos.
- Proyectos especiales.

## Inicio

La nueva portada incluye:

1. Hero con mensaje amplio de merchandising.
2. Segmentos de cliente.
3. Categorías visuales.
4. Productos destacados con imagen 4:5 estándar.
5. Banner de ofertas con formato 1200 × 628.
6. Flujo seguro de solicitud.
7. Soluciones empresariales.
8. Prueba social / confianza.

## Solicitud web

La web pública mantiene separado el concepto de solicitud del pedido operativo.

Una solicitud web:

- No descuenta inventario.
- No crea movimientos financieros.
- No entra a producción.
- Debe validarse antes de convertirse en cotización o pedido.

La integración segura con Beheer sigue definida en `INTEGRACION-BEHEER.md`.

## Catálogo

El catálogo se obtiene exclusivamente de la API pública de Beheer. No existe un catálogo local de respaldo.

Las fotografías editoriales se centralizan en `media-config.js`; las imágenes de producto provienen de `imagenWeb` en Beheer.
